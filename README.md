# Snap & Study 📚

AI Study Assistant built with Streamlit and Gemini.

## Planned features
- Text questions
- Image/question upload
- Gemini explanations
- Conversation memory
- Study-summary email

## Run locally

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Never commit `.streamlit/secrets.toml`.
